# ARCHITECTURE

- `crates/dd-proto` (pure): `model.rs` Model/Identity/KeyDef layout; `keymap.rs` KeyAction{cmd,kind,code}.encode(slot), Keymap 3x126, factory() from `data/*.json`; `packets.rs` builders/parsers + expected_reply; `rtp.rs` LW/RDT/RT Match/slots; `catalog.rs` picker categories + label().
- `app/src/hid.rs`: enumerate (SetupDi*, HidD_GetAttributes, HidP_GetCaps), HidDevice::open (overlapped), write_report, read_report(timeout). `lock(ms)` = named mutex `Local\KrakenControlHid` (UI + agent share the device; one request in flight). Stub on non-Windows unless `check-win`.
- `app/src/device.rs`: UI worker thread. Session{dev, identity, quiet}: drain(), request() (skips unrelated reports), pull(kind), pull_pairs(), snapshot(), write_all(). Every connect/command/ping runs under `hid::lock` + drain. Idle ping 3 s (not packet-logged) detects slot change -> Snapshot. `one_shot(wait, f)` = open/lock/identify for short transactions (agent).
- `app/src/agent.rs`: `--agent` tray mode, no eframe/GL. Hidden top-level window (class `KrakenControlAgent`, per-monitor DPI aware), Shell_NotifyIcon (re-added on TaskbarCreated), popup menu (open UI, slots, per-app toggle, start with Windows, exit), SetWinEventHook(EVENT_SYSTEM_FOREGROUND, out-of-context) -> 300 ms debounce -> exe name -> AgentConfig rule -> worker thread -> one_shot FB 05. State in thread_local RefCell, never borrowed across TrackPopupMenu.
- `app/src/sys.rs`: single instance (named mutex), process names (QueryFullProcessImageNameW), find/focus UI window (title + exe), running apps (EnumWindows), HKCU Run autostart, agent start/stop (spawn self / WM_CLOSE).
- `app/src/icon.rs`: embedded `res/kraken.ico`; `rgba(64)` for the window icon, `best(px)` -> CreateIconFromResourceEx for the tray.
- `app/build.rs`: MSVC only — writes `OUT_DIR/kraken.res` (RT_ICON x8, RT_GROUP_ICON 1, VERSIONINFO from CARGO_PKG_VERSION) and passes it via `cargo:rustc-link-arg-bins`.
- `main.rs`: legacy migration (close old agent, move Run value, move %APPDATA% folder) runs before the first log line.
- Renderers: `main.rs` picks software (`soft::run`, default) or GPU (`eframe::run_native`) from `settings.renderer` / `--gpu` / `--software`. `soft.rs`: winit ApplicationHandler `Shell` (window, softbuffer surface, egui_winit::State, ViewportInfo), paints on RedrawRequested, schedules repaints from egui's repaint delay and the request_repaint callback (user event with pass nr). `raster.rs`: `Raster` textures (TexturesDelta set/free, font atlas via srgba_pixels) + `paint` into 0x00RRGGBB buffer, bands per thread.
- `app/src/backup.rs`: back-up file format + import checks (pure; gen-2 keyboard part applied by `Gen2Panel::import_backup` / exported by `export_backup`). `ui.rs` `backup_card` / `export_to` / `apply_import` / `merge_kraken`; dialogs via `sys::file_dialog` on a worker thread (`backup_job` channel).
- `app/src/mem.rs`: `#[global_allocator]` counting wrapper over System (heap now/peak), `process()` OS counters, `summary(atlas)` line for log + Settings.
- `app/src/theme.rs`: themes (`ThemeId`, `Palette` roles, `pal()` reads an AtomicU8), fonts (`app/res/fonts`, family `bold()` for headings/labels), `Page` enum shared by both boards, widgets (card, setting, switch, nav, keycap, plate, no_keyboard, status_line). `apply(ctx, id)` on start and on theme change only.
- Shell (`ui.rs` `update`): header TopBottomPanel, status bar, nav SidePanel (196 px), CentralPanel -> `gen1_page` / `gen2_page` (page header + one ScrollArea for every page; no inner scroll areas). Keyboard size = `theme::key_unit` (width only).
- Lighting presets: `theme::presets_row` -> `PresetAction`; gen-1 `App::light_presets` (store.light_presets), gen-2 `Gen2Panel::light_presets` (store.light_presets2 passed into `body`, returns changed).
- `app/src/ui.rs`: App state (working values + synced copies for dirty tracking), canvas painter, tabs Performance / Remap / Last Win-RDT / Per-app-tray, profiles. `--demo`, `--tab=remap|pairs|rdt|apps`.
- `app/src/store.rs`: `state.json` (keymaps, profiles, settings) and `agent.json` (auto_switch, default_slot, rules) — separate so UI and agent read-modify-write only the small file; agent reloads on mtime change. Atomic tmp+rename.
- Gen-2 (VID 0x19F5): `dd-proto/src/gen2.rs` (pure: framing, Trigger raw record, Action/labels, layout K75 + `match_layout`, `func` fields), `app/src/device2.rs` (worker thread, `hid::candidates_gen2()` = usage page 1 / usage 0, report ID 0, reply `AA` data@8), `app/src/ui2.rs` (`Gen2Panel`: own tabs; hosted by `ui.rs` via `Board` switch + `board_selector`).
- `ui2.rs` live lighting: `LIGHTING` fields + colours sent by `live_lighting()` (called each frame from `central`) via existing SaveFunc/SaveColors; `light_edit_at` debounce; local `busy=true` on send. `Event::Func/Colors` merged with `merge_pending(work, old_snap, new)` (keep elements where work != old snap). Brush = `paint_stroke()` (primary press on keyboard area via `rect_contains_pointer`, samples segment every 0.2 key units).
- `dd-proto/src/pattern.rs`: pure per-key colour generators from key centres (layout key x+w/2, y+h/2); UI maps layout index -> slot via `slots` in `ui2::set_key_colors` (also logs `gen2 ui: <what>: N keys changed`).
- `store.rs`: `data_dir()` / `portable_dir()` decide where state.json, agent.json, log.txt live (all derive from `Store::path()`). `packaging/package.ps1`: dd-proto tests, `RUSTFLAGS=+crt-static` build into `target\portable`, zip to `dist\`.
- Gen-1 lighting: `dd-proto/src/led.rs` (EFFECTS, PRESETS, `effect()`, `custom()`), `device::Cmd::Lighting` (write_all, ack only), `ui.rs` Tab::Lighting (`lighting_tab`, `light_custom_tools`, `light_paint_stroke`, `light_live`), `store::Lighting1` per model.
