# Code of conduct

Kraken Control is a small hobby project. Everyone taking part in issues, pull
requests and discussions here is expected to:

- Be respectful and assume good intent, whatever someone's experience level.
- Keep feedback about the work, not the person.
- Stay on topic and help others reproduce or fix problems.

Not accepted: harassment, insults, discrimination, personal attacks, spam, or
sharing someone else's private information.

Maintainers may edit or remove comments, close issues, or block users who
break these rules. To report a problem with someone's behaviour, use
**Report content** on the comment, or contact the maintainer through GitHub.
